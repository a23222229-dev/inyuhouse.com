## 服務內容

### 四大標準化服務流程

1. **資產評估**：以數據進行精準健檢，評估地段發展性、屋況體質、客群定位與潛在租金投報。
2. **空間升級**：以投報率為導向的輕裝修，專注於能顯著提升租金與出租率的核心項目。
3. **高效包租**：漏斗式嚴格把關租客品質，從行銷曝光、信用與背景審核，到生活習慣深度面談。
4. **穩健收益**：零空窗期焦慮、每月準時入帳、定期屋況巡檢，讓資產持續保值。

### 合作方案

| 方案 | 適用對象 | 特色 |
| --- | --- | --- |
| **方案 A：全效包租** | 追求絕對零風險、不想處理任何瑣事的房東 | 盈寓承擔所有空窗期風險，保證每月固定收益，並負責全額或部分裝修升級 |
| **方案 B：輕裝代管** | 希望保留較高租金利潤，且願意承擔微小市場波動的房東 | 房東享有實際租金收益扣除代管費，盈寓提供專業升級建議與全方位物業管理 |
